## 📖 Passo a passo

1. Abra o navegador e acesse o gerenciador de favoritos.
2. Crie um novo favorito.
3. Coloque o nome correspondente: **Quizizz**, **Redação Paraná** ou **Leia Paraná**.
4. Copie o código correspondente acima e cole no campo de URL do favorito.
5. Salve o favorito.
6. Abra a página correspondente e clique no favorito para executar o script.

**Importante:** confira o código-fonte antes de executar scripts externos. Nunca compartilhe sua chave da API do OpenRouter publicamente.
